🐴 herdr 2×2 split

🤖 Claude commanded herdr to divide one screen into four panes.

1️⃣ w4:p1🤖 Claude (this session)
2️⃣ w4:p2new shell
3️⃣ w4:p3new shell
4️⃣ w4:p4new shell

✅ What happened

I asked Claude to split my herdr screen into 4. Claude ran the herdr pane split CLI itself, with no keyboard shortcuts, and the layout came out as four equal 109×36 panes.

herdr pane split w4:p1 --direction right --ratio 0.5
herdr pane split w4:p1 --direction down  --ratio 0.5
herdr pane split w4:p2 --direction down  --ratio 0.5

🙏 Thanks

Thanks to Onuralp for reminding me to use herdr. I don't remember the keyboard shortcuts, so having Claude command herdr through its CLI is perfect. 🎉

🧩 Prompt helper

🛠️ Build a prompt that makes Claude Code split herdr into planes and start one agent per plane.

#📛 Plane name🤖 Agent

🧠 Agent options: claude, antigravity (herdr kind agy), kilo, mimo (not a herdr agent kind, so it runs as a plain command in its pane). Choose "none" to leave a plane empty.

📎 Paste it into Claude Code in your herdr pane. It will read the pane IDs from the JSON it gets back.
